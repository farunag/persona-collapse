# Persona Collapse workbench

The same long conversations with Qwen 3 32B and Gemma 2 27B in English, Hausa and Yoruba,
with each reply's reading on the Assistant Axis (Lu et al. 2026), default and capped side by side.

- Data: [Faruna01/persona-collapse-runs](https://huggingface.co/datasets/Faruna01/persona-collapse-runs)
- Code: [github.com/farunag/persona-collapse](https://github.com/farunag/persona-collapse)

Content warning: the therapy conversations discuss distress. This is a research tool, not support.
