Reading the trace

Each row is one turn. Further right is closer to the model's default assistant (1.0); the dashed line at 0 is where an average role-played character sits. Click a row or a message to line both chats up on that turn.

A steady reading is not a good answer

In Hausa and Yoruba the model often stays near its assistant mode while missing what the user said. Read the replies, not only the trace.

How it was made

Each conversation was written once in English, and its user messages were translated into Hausa and Yoruba and checked by native speakers. Qwen 3 32B answered every message fresh in each language, with no instructions about length; replies stop at 400 tokens.
